Single-Scale Alignment

First, naive windowed search on lower resolution JPEGs was explored. This algorithm exhaustivley searches over shifts \((\Delta x,\Delta y)\in[-r,r]^2\) scales with both window size and image area:

\[ T_{\text{single}} \;\approx\; (2r+1)^2 \cdot N \]

where \(N\) is the # of overlapping pixels approx(width × height). Doubling the image resolution or widening the window of course leads to much higher runtimes.

Scoring

NCC (Normalized Cross-Correlation) seek to maximise:

\[ \mathrm{NCC}(A,B) \;=\; \frac{\sum (A-\bar A)(B-\bar B)} {\sqrt{\sum (A-\bar A)^2}\;\sqrt{\sum (B-\bar B)^2}} \]

L2 (sum of squared differences) minimise:

\[ \mathrm{L2}(A,B) \;=\; \sum (A - B)^2 \]

Behind the scenes, a small interior border gets cropped so that the gram artifacts are ingored (as sometimes only a single slide captured light from some bordering region). Then the score for each shift is evaluated and the best is taken \((\Delta x,\Delta y)\) for \(G\!\to\!B\) and \(R\!\to\!B\), then stack to RGB.

Multi scale Pyramid Alignment

Exhaustive window search becomes intractably when the possible displacement \((\Delta x,\Delta y)\) gets big Thus, a Gaussian image pyrmaid fixes this by aligning at a coarse scale, then successively refining at finer scales using a tiny local search. This algorithmics workings are explored further.

\[ T_{\text{single}} \;\approx\; (2r+1)^2\,N \]

where \(r\) is the half window and \(N\) is the # of overlapping pixels. Runtime grows quadratically with \(r\) and linearly with image area. A huge improvemnt from before!

For a pyramid with downsample factor 2 and levels \(\ell=0\) (coarsest) … \(L-1\) (finest), each level has \(N_\ell \approx N/4^{\,\ell}\). A broader search only at the top level is done (radius \(r_c\)), then a small local search (radius \(r_f\)) at the finer levels:

\[ T_{\text{pyr}} \;\approx\; \sum_{\ell=0}^{L-1} (2r_\ell+1)^2\,N_\ell, \qquad N_\ell \approx \frac{N}{4^{\,\ell}} \]

If \(r_f\) is a small and only the top level uses a larger \(r_c\), then \[ T_{\text{pyr}} \;\lesssim\; \underbrace{(2r_c{+}1)^2\,\frac{N}{4^{\,L-1}}}_{\text{tiny}} \;+\; (2r_f{+}1)^2 \sum_{\ell=0}^{L-2}\frac{N}{4^{\,\ell}} \;\le\; \frac{4}{3}\, (2r_f{+}1)^2\, N \;=\; \mathcal{O}(N). \] So instead of one huge search we do a few tiny ones leading to asymptotically linear work.

The running translation estimate \((d_y,d_x)\) is propagated upward: \[ (d_y,d_x)_{\ell-1} \;=\; 2\,(d_y,d_x)_\ell \;+\; \delta_\ell, \] where \(\delta_\ell\) is the best lcal shift found at level \(\ell\).

Edge Based Alignment

Raw pixel intensities can disagree across channels, like was seem with Emir's cyan robe vs the R channel. Edges have a shared strucutre largely, and thus we can try aligned on the gradient magnitude of a smoothy image, as smoothing helps properly alignment, pronnoncing edges.

Smooth → Differentiate (like how was seen in lecture):

\[ f_\sigma \;=\; f * g_\sigma,\quad f_x \approx k_x * f_\sigma,\quad f_y \approx k_y * f_\sigma,\quad \|\nabla f_\sigma\| \;=\; \sqrt{f_x^2 + f_y^2}. \]

Additioanlly, for efficiency we leverage the fact that: convolution is associative/commutative, so

\[ \nabla(f * g_\sigma) \;=\; (\nabla f) * g_\sigma \;=\; f * (\nabla g_\sigma). \]

Saving one operation per photo since we only have to apply the 'mega-convolved' filter. Then this process scores patches using NCC on \(\|\nabla f_\sigma\|\), which is more invariant to odd colour saturations than raw pixels.

Emir improves: his robe’s color swaps cause pixels seem to cause mismatch across channels, but all the seams, edges, contours and folds aligned in this way stay constant with eachother.Aligning on \(\|\nabla f_\sigma\|\) removes the color-bias and it seems produces the sharpest result.
